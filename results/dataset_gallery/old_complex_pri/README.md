## Historical protocol

This is the previous 1024-observed-interval dataset. Losses may occur anywhere, including future target positions. The figure shows all 1024 intervals of seq_0800.

The original local production audit reported 128 datasets and 128000 sequences with 700/100/200 splits. The dataset source root is now datasets/old_complex_pri.
