## Current protocol

This is new_complex_pri. Each panel shows the last 96 observed context intervals and the next 32 consecutive source future pulses of seq_0800. The dotted boundary starts the future; configured measurement noise is retained.

The local production collection is complete. Its full generation validator was interrupted before the final report, so these examples do not claim a completed production audit.
