# Consecutive future v2 implementation checks

Implementation and checks were performed on `long-seq-1024`. At the time of these
implementation checks, full production generation and training had not been
started. Existing datasets and historical experiment outputs were not modified.

## Storage and protocol

- New writes use one per-sequence CSV. `write_split` writes incrementally and
  keeps a scalar row count instead of retaining every sequence and concatenating
  the entire split. It does not write `sequences.csv`.
- In v2, each CSV is the authoritative source stream plus loss masks and selected
  row indices. There is no duplicate model-facing CSV or separate PDW trace.
- Projection gives an anchor, 1024 observed context intervals and 32 consecutive
  source future pulses. POI/global losses apply to whole PDW rows in context;
  future source IDs continue directly after the last retained context ID.
- Boundary mode keeps target positions fixed across L and uses target prefixes
  across H. Source modulation laws and configured numeric parameters are retained.
